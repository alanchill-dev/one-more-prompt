# One More Prompt v1.0.0 — 릴리스 노트

[English](v1.0.0.md) · [繁體中文](v1.0.0.zh-TW.md) · [简体中文](v1.0.0.zh-CN.md) · [日本語](v1.0.0.ja.md) · **한국어** · [Español](v1.0.0.es.md) · [Português (Brasil)](v1.0.0.pt-BR.md) · [Deutsch](v1.0.0.de.md) · [Français](v1.0.0.fr.md)

> v1.0.0은 첫 정식 공개 버전입니다. macOS(Apple Silicon) 및 Windows(x64) 패키지를 제공합니다.

## 주요 변경

- Codex 전용 작업 공간: 계정 한도, 초기화 시간, 로컬 Token 활동, 프로젝트, 타임라인.
- 기본은 오늘 보기이며 모델 색상과 Token/API 환산 금액 전환을 지원합니다. 추정액, 모델 단가, 계산 내역은 선택한 통화를 사용하며, 비교용이지 청구액은 아닙니다.
- 프로젝트 → 세션 → 프롬프트에서 원문, 실행 시간, 모델, 주/하위 에이전트 사용량을 확인합니다. 고정 상태는 날짜 변경 후에도 유지됩니다. 누락된 시간이나 실행 중인 작업을 포함한 합계에는 `>`가 표시됩니다.
- 일반 `.jsonl`과 압축 `.jsonl.zst` 기록의 계산, 날짜, Prompt ID 및 탐색 동작이 같습니다. 스캔은 실제 확인/전체 파일 수를 표시합니다.
- 3개 화면으로 된 최초 설정은 언어 선택부터 시작하며 저장한 언어를 작업 공간과 선택형 가이드에서도 사용합니다. 데모 프로젝트, 대화, 프롬프트, 에이전트 설명은 9개 언어로 제공됩니다. 가이드 다시 보기와 Codex 다시 확인은 분리되며 최초 설정은 필수입니다.
- One More Prompt 앱 식별자와 내부 이름을 통일하고 기존 제품 데이터 및 설정을 한 번 마이그레이션합니다.
- 영어 기본값 외에 번체·간체 중국어, 일본어, 한국어, 스페인어, 브라질 포르투갈어, 독일어 및 프랑스어를 지원합니다.
- 안정 버전을 자동 확인하며 설정의 수동 확인 메뉴는 항상 사용할 수 있습니다. 현재 플랫폼용 새 안정 버전이 확인된 경우에만 설정 바로 왼쪽에 알림 점이 있는 간결한 업데이트 아이콘이 나타납니다. 다운로드는 외부에서 열리며 앱 교체는 수동입니다.
- 일반 및 압축 기록의 중복 기록, 이어진 세션, 스레드 간 중복 제거와 추론 Token 합계를 수정했습니다. API 추정값은 측정된 캐시 쓰기를 유지하며 단가가 없으면 이유와 계산 가능한 소계를 표시합니다.
- 새 성공 결과가 나올 때까지 새로고침 실패 안내를 유지합니다. 진단 마스킹, Codex 캐시 범위, 마이그레이션 재시도 정리, Windows 자동 시작과 트레이 열기 동작을 개선했습니다.

## 패키지

- macOS Apple Silicon: `One-More-Prompt-1.0.0.dmg`, Developer ID 서명 및 Apple 공증.
- Windows x64: `One-More-Prompt-1.0.0-windows-x64-portable.zip`, 미서명. 전체 폴더를 압축 해제하고 `one-more-prompt.exe`를 실행합니다.

SHA-256: [SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt) / [SHA256SUMS-windows.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS-windows.txt)

앱을 설치하거나 실행할 때는 DMG 또는 ZIP만 다운로드하면 됩니다. [SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt)에는 다운로드한 파일의 무결성을 선택적으로 확인할 수 있는 해시가 있으며, 설치 프로그램이나 디지털 서명이 아닙니다.

## 주의 사항

- Windows에는 Microsoft WebView2가 필요합니다. SmartScreen이나 조직 정책이 경고하거나 차단할 수 있습니다. 설정은 일반 사용자 데이터 위치에 있으며 ZIP과 함께 이동하지 않습니다.
- macOS 앱 또는 전체 Windows 폴더를 교체하기 전에 앱을 종료하세요. 설정과 로컬 데이터는 유지됩니다. 자동 설치, 업데이터 피드, 관리자 설정 절차는 없습니다.
- 버전 확인은 프로젝트 GitHub 안정 버전 엔드포인트에 익명으로 요청하며 Codex 인증 정보, 프롬프트, 프로젝트명, 대화 기록을 보내지 않습니다.
- Linux, Intel Mac, 네이티브 Windows ARM 및 사용자 지정 Windows Credential Manager 저장은 지원하지 않습니다.
- 자동 테스트, 패키지 검사, 현재 사용자 계정에서의 macOS 실행 확인을 완료했습니다. 이 패키지에 대한 Windows x64 및 깨끗한 macOS 계정의 전체 인수 검증은 다시 수행하지 않았으며, 소유자는 이 제한을 확인하고 공개를 승인했습니다.
