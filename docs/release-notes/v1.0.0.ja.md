# One More Prompt v1.0.0 — リリースノート

[English](v1.0.0.md) · [繁體中文](v1.0.0.zh-TW.md) · [简体中文](v1.0.0.zh-CN.md) · **日本語** · [한국어](v1.0.0.ko.md) · [Español](v1.0.0.es.md) · [Português (Brasil)](v1.0.0.pt-BR.md) · [Deutsch](v1.0.0.de.md) · [Français](v1.0.0.fr.md)

> v1.0.0 は初の正式公開版です。macOS（Apple Silicon）と Windows（x64）向けのパッケージを提供します。

## 主な変更

- Codex に特化したワークスペース：アカウント上限、リセット時刻、ローカルの Token 活動、プロジェクト、タイムライン。
- 既定は今日。モデル配色と Token／API 換算額の切り替えに対応。換算額、モデル単価、計算内訳は選択した通貨で表示します。比較用で、請求額ではありません。
- プロジェクト → セッション → プロンプトから原文、実行時間、モデル、メイン／サブエージェントの使用量を確認。ピン留めは日付変更後も保持します。時間記録の欠落や実行中の仕事を含む合計には `>` を付けます。
- 通常の `.jsonl` と圧縮された `.jsonl.zst` で、集計、日付、Prompt ID、閲覧動作を共通化。スキャンは実際の確認済み／総ファイル数を表示します。
- 3画面の初回設定は言語選択から始まり、保存した言語をワークスペースと任意のガイドでも使います。デモのプロジェクト、会話、プロンプト、エージェント説明は9言語に対応。ガイド再生と Codex 再確認は別で、初回設定は必須です。
- One More Prompt のアプリ識別子と内部名称を統一し、既存の製品データと設定を一度だけ移行します。
- 英語を既定とし、繁体字中国語、簡体字中国語、日本語、韓国語、スペイン語、ブラジルポルトガル語、ドイツ語、フランス語にも対応。
- 安定版を自動確認し、設定からの手動確認は常に利用できます。このプラットフォーム向けの新しい安定版が確認された場合にのみ、設定のすぐ左に通知点付きの小さな更新アイコンが現れます。ダウンロードは外部で開き、アプリの置き換えは手動です。
- 非圧縮・圧縮履歴の重複記録、継続セッション、スレッド間の重複除去、推論 Token の合計を修正しました。API 換算は記録されたキャッシュ書き込みを保持し、不明な単価を説明して算出可能な小計を表示します。
- 更新失敗の表示は、新しい成功結果が届くまで保持されます。診断情報のマスキング、Codex キャッシュの範囲、移行再試行時の一時データ削除、Windows 自動起動、トレイの「開く」を改善しました。

## パッケージ

- macOS Apple Silicon：`One-More-Prompt-1.0.0.dmg`。Developer ID 署名・Apple 公証済み。
- Windows x64：`One-More-Prompt-1.0.0-windows-x64-portable.zip`。署名なし。フォルダ全体を展開して `one-more-prompt.exe` を起動します。

SHA-256: `SHA256SUMS.txt` / `SHA256SUMS-windows.txt`

## 注意事項

- Windows では Microsoft WebView2 が必要です。SmartScreen や組織ポリシーで警告・ブロックされる場合があります。設定は通常のユーザーデータ領域にあり、ZIP と一緒には移動しません。
- macOS アプリや Windows フォルダ全体を置き換える前に終了してください。設定とローカルデータは保持します。自動インストール、アップデーターフィード、管理者向け設定処理は含みません。
- バージョン確認はプロジェクトの GitHub 安定版エンドポイントを匿名で参照し、Codex 認証情報、プロンプト、プロジェクト名、会話履歴を送りません。
- Linux、Intel Mac、ネイティブ Windows ARM、独自の Windows Credential Manager 保存には対応していません。
- 自動テスト、パッケージ検査、現在のユーザーアカウントでの macOS 起動確認を実施しました。このパッケージでは Windows x64 とクリーンな macOS アカウントでの完全な受け入れ検証は再実施していません。所有者はこの制限を確認したうえで公開を承認しました。
