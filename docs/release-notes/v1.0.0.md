# One More Prompt v1.0.0 — Release Notes

**English** · [繁體中文](v1.0.0.zh-TW.md) · [简体中文](v1.0.0.zh-CN.md) · [日本語](v1.0.0.ja.md) · [한국어](v1.0.0.ko.md) · [Español](v1.0.0.es.md) · [Português (Brasil)](v1.0.0.pt-BR.md) · [Deutsch](v1.0.0.de.md) · [Français](v1.0.0.fr.md)

> v1.0.0 is the first stable public release for macOS (Apple Silicon) and Windows (x64).

## Highlights

- One focused Codex workspace: account limits, reset times, local Token activity, Projects, and Timeline.
- Today by default, model palette customization, and complete Tokens/API Valuation switching. Estimates, model prices, and calculation breakdowns use the selected currency. API valuation is a usage comparison, not your bill.
- Project → Session → Prompt browsing with original text, execution time, model usage, and main/sub-agent contributions. Saved project and session pins survive date changes. A `>` flags a time total with missing durations or work still running.
- Ordinary `.jsonl` and compressed `.jsonl.zst` history share accounting, dates, Prompt IDs, and browsing behavior; scans show real checked/total file progress.
- Three-screen first setup starts with language selection, saves it, and carries it into the workspace and optional guide. Demo projects, sessions, prompts, and agent descriptions are localized in all nine languages. Replay Guide and Recheck Codex have separate entries; first setup remains required.
- New One More Prompt application identity and internal names, with one-time migration of existing product data and settings.
- English by default, with Traditional Chinese, Simplified Chinese, Japanese, Korean, Spanish, Brazilian Portuguese, German, and French.
- Automatic stable-release checks, with manual Check for Updates always available in Settings. The compact icon with a dot appears immediately left of Settings only when a newer stable release for the current platform is confirmed. Downloads open externally; replacing the app remains manual.
- Corrected repeated and continued-session Token totals, cross-thread deduplication, and reasoning totals in ordinary and compressed history. API estimates retain measured cache writes and explain missing prices with the available subtotal.
- Refresh failures remain visible until a newer success. Diagnostic masking, Codex-only cache isolation, migration retry cleanup, Windows startup registration, and the tray Open action are more reliable.

## Packages

- macOS Apple Silicon: `One-More-Prompt-1.0.0.dmg`, Developer ID signed and Apple notarized.
- Windows x64: `One-More-Prompt-1.0.0-windows-x64-portable.zip`, unsigned; extract the entire folder and run `one-more-prompt.exe`.

SHA-256: [SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt) / [SHA256SUMS-windows.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS-windows.txt)

Only the DMG or ZIP is needed to install or run the app. [SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt) lists hashes for optional download-integrity checks; it is neither an installer nor a digital signature.

## Important Details

- Windows requires Microsoft WebView2. SmartScreen or company policy may warn about or block unsigned apps. Settings use normal per-user storage and do not travel with the ZIP.
- Quit before replacing the macOS app or complete Windows folder. Preferences and local data are retained. No automatic installation, updater feed, or administrator setup is included.
- Release checks anonymously query the project’s GitHub stable-release endpoint. No Codex credentials, prompts, project names, or session history are sent.
- Linux, Intel Mac, native Windows ARM, and custom Windows Credential Manager storage are not included.
- Verification includes automated tests, package checks, and a current-user macOS launch check. Windows x64 and clean-account macOS acceptance were not rerun for these packages; the owner approved publication with those limits disclosed.
