# One More Prompt v1.0.0 — Notes de Version

[English](v1.0.0.md) · [繁體中文](v1.0.0.zh-TW.md) · [简体中文](v1.0.0.zh-CN.md) · [日本語](v1.0.0.ja.md) · [한국어](v1.0.0.ko.md) · [Español](v1.0.0.es.md) · [Português (Brasil)](v1.0.0.pt-BR.md) · [Deutsch](v1.0.0.de.md) · **Français**

> v1.0.0 est la première version publique stable pour macOS (Apple Silicon) et Windows (x64).

## Nouveautés

- Un espace consacré à Codex : limites de compte, réinitialisations, activité locale des Tokens, Projets et Chronologie.
- Aujourd’hui par défaut, couleurs de modèles personnalisables et bascule complète Tokens/estimation API. Les estimations, prix des modèles et détails de calcul utilisent la devise choisie. Ils servent de repère, pas de facture.
- Navigation Projet → Session → Prompt avec texte original, durée, modèles et contributions des agents principaux/secondaires. Les éléments épinglés restent lors des changements de date. Un `>` indique un total avec des durées manquantes ou du travail encore en cours.
- Les fichiers `.jsonl` ordinaires et `.jsonl.zst` compressés partagent calculs, dates, identifiants de prompts et navigation. L’analyse affiche le nombre réel de fichiers vérifiés et le total.
- La configuration initiale en trois écrans commence par le choix de la langue, enregistrée pour l’espace de travail et le guide facultatif. Projets, sessions, prompts et descriptions d’agents de démonstration sont traduits dans les neuf langues. Revoir le guide et revérifier Codex restent séparés ; la première configuration est obligatoire.
- Identité de l’application et noms internes unifiés sous One More Prompt, avec migration unique des données et réglages existants.
- Anglais par défaut, plus chinois traditionnel et simplifié, japonais, coréen, espagnol, portugais du Brésil, allemand et français.
- Vérification automatique des versions stables, avec vérification manuelle toujours accessible dans les réglages. L’icône compacte avec un point apparaît immédiatement à gauche des réglages uniquement lorsqu’une version stable plus récente pour la plateforme actuelle est confirmée. Les téléchargements s’ouvrent à l’extérieur ; le remplacement reste manuel.
- Correction des totaux de Tokens des entrées répétées et des sessions poursuivies, de la déduplication entre conversations et des totaux de raisonnement dans les historiques ordinaires et compressés. Les estimations API conservent les écritures en cache mesurées et expliquent les prix manquants avec le sous-total disponible.
- Les erreurs de mise à jour restent visibles jusqu’à un résultat réussi plus récent. Amélioration du masquage des diagnostics, de l’isolation du cache Codex, du nettoyage des nouvelles tentatives de migration, du démarrage Windows et de l’action Ouvrir de la zone de notification.

## Paquets

- macOS Apple Silicon : `One-More-Prompt-1.0.0.dmg`, signé avec Developer ID et notarié par Apple.
- Windows x64 : `One-More-Prompt-1.0.0-windows-x64-portable.zip`, non signé ; extrayez tout le dossier et lancez `one-more-prompt.exe`.

SHA-256: `SHA256SUMS.txt` / `SHA256SUMS-windows.txt`

## Points Importants

- Windows nécessite Microsoft WebView2. SmartScreen ou une politique d’entreprise peut avertir ou bloquer les apps non signées. Les réglages restent dans les données habituelles de l’utilisateur et ne suivent pas le ZIP.
- Quittez avant de remplacer l’app macOS ou tout le dossier Windows. Préférences et données locales sont conservées. Ni installation automatique, ni flux de mise à jour, ni configuration administrateur.
- Les vérifications interrogent anonymement le point d’accès GitHub stable du projet, sans envoyer d’identifiants Codex, prompts, noms de projets ou historique de conversations.
- Linux, Mac Intel, Windows ARM natif et le stockage personnalisé Windows Credential Manager ne sont pas inclus.
- La vérification comprend des tests automatisés, des contrôles des paquets et un test de lancement de macOS dans le compte actuel. Les tests complets d’acceptation sous Windows x64 et dans un compte macOS vierge n’ont pas été répétés pour ces paquets ; le propriétaire a approuvé la publication en connaissance de ces limites.
