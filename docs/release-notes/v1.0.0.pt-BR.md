# One More Prompt v1.0.0 — Notas da Versão

> v1.0.0 é a primeira versão pública estável para macOS (Apple Silicon) e Windows (x64).

## Destaques

- Um espaço focado no Codex: limites da conta, redefinições, atividade local de Tokens, Projetos e Linha do tempo.
- Hoje como visualização inicial, cores de modelos e alternância completa entre Tokens e estimativa de API. Estimativas, preços de modelos e cálculos usam a moeda selecionada; são uma referência de uso, não uma fatura.
- Navegação Projeto → Sessão → Prompt com texto original, tempo de execução, modelos e agentes principais/secundários. Itens fixados permanecem ao mudar de data. Um `>` identifica totais com durações ausentes ou trabalho ainda em execução.
- Registros `.jsonl` comuns e `.jsonl.zst` compactados compartilham cálculos, datas, IDs de prompts e navegação. A verificação mostra os arquivos realmente conferidos e o total.
- A configuração inicial de três telas começa pela escolha e gravação do idioma, mantido no espaço de trabalho e no guia opcional. Projetos, sessões, prompts e descrições de agentes de demonstração estão nos nove idiomas. Rever o guia e verificar o Codex têm entradas separadas; a configuração inicial continua obrigatória.
- Identidade do aplicativo e nomes internos unificados em One More Prompt, com migração única dos dados e ajustes existentes.
- Inglês por padrão, além de chinês tradicional e simplificado, japonês, coreano, espanhol, português do Brasil, alemão e francês.
- Verificação automática de versões estáveis, com a verificação manual sempre disponível em Configurações. O ícone compacto com um ponto só aparece imediatamente à esquerda de Configurações após confirmar uma versão estável mais recente para a plataforma atual. Downloads abrem externamente e a substituição permanece manual.
- Corrigidos os totais de Tokens de registros repetidos e sessões continuadas, a deduplicação entre conversas e os totais de raciocínio em históricos comuns e compactados. As estimativas API preservam as gravações de cache medidas e explicam os preços ausentes com o subtotal disponível.
- As falhas de atualização permanecem visíveis até um resultado bem-sucedido mais recente. Foram aprimorados o mascaramento dos diagnósticos, o isolamento do cache do Codex, a limpeza nas novas tentativas de migração, a inicialização do Windows e a ação Abrir da bandeja.

## Pacotes

- macOS Apple Silicon: `One-More-Prompt-1.0.0.dmg`, assinado com Developer ID e notarizado pela Apple.
- Windows x64: `One-More-Prompt-1.0.0-windows-x64-portable.zip`, sem assinatura; extraia toda a pasta e execute `one-more-prompt.exe`.

SHA-256: `SHA256SUMS.txt` / `SHA256SUMS-windows.txt`

## Detalhes Importantes

- O Windows exige Microsoft WebView2. O SmartScreen ou políticas corporativas podem alertar ou bloquear apps sem assinatura. Os ajustes ficam nos dados normais do usuário e não acompanham o ZIP.
- Encerre o app antes de substituir o aplicativo no macOS ou toda a pasta no Windows. Preferências e dados locais são preservados. Não há instalação automática, feed de atualização nem configuração de administrador.
- A consulta acessa anonimamente o endpoint de versão estável do projeto no GitHub, sem enviar credenciais Codex, prompts, nomes de projetos ou histórico de conversas.
- Não inclui Linux, Mac Intel, Windows ARM nativo nem armazenamento personalizado do Windows Credential Manager.
- A verificação inclui testes automatizados, verificações dos pacotes e um teste de inicialização do macOS na conta atual. Os testes completos de aceitação de Windows x64 e macOS com uma conta limpa não foram repetidos para estes pacotes; o proprietário aprovou a publicação ciente dessas limitações.
