# One More Prompt v1.0.0 — 版本说明

[English](v1.0.0.md) · [繁體中文](v1.0.0.zh-TW.md) · **简体中文** · [日本語](v1.0.0.ja.md) · [한국어](v1.0.0.ko.md) · [Español](v1.0.0.es.md) · [Português (Brasil)](v1.0.0.pt-BR.md) · [Deutsch](v1.0.0.de.md) · [Français](v1.0.0.fr.md)

> v1.0.0 是首个正式公开版本，提供 macOS（Apple Silicon）与 Windows（x64）安装包。

## 亮点

- 专注 Codex 的工作区：账号额度、重置时间、本地 Token 活动、项目与时间轴。
- 默认显示今天，支持模型配色和完整 Token／API 估值切换；估值、模型单价和计算明细使用所选货币，仅用于比较用量，并非实际账单。
- 按「项目 → 会话 → 提示词」查看原文、执行时间、模型及主／子代理用量；项目和会话固定状态跨日期保留。`>` 提醒总时长含有缺失记录或仍在运行的工作。
- 普通 `.jsonl` 和压缩 `.jsonl.zst` 记录共用计算、日期、提示词 ID 与浏览方式；扫描显示真实已检查／总文件进度。
- 三页首次设置先选择并保存语言，工作区和可选导览沿用该选择。示例项目、会话、提示词与代理说明均提供九种语言；重新观看导览和重新检查 Codex 分开，首次设置仍必须完成。
- 统一 One More Prompt 应用标识与内部命名，通过一次性迁移保留现有产品数据及设置。
- 英文为默认语言，另提供繁体中文、简体中文、日语、韩语、西班牙语、巴西葡萄牙语、德语和法语。
- 自动检查正式新版，设置中的手动检查入口始终保留。只有确认当前平台有更新的正式版时，设置左侧才会出现带提示点的简洁更新图标。通过外部浏览器下载，仍需手动替换应用。
- 修正未压缩与压缩历史中的重复记录、续接对话、跨对话去重与推理 Token 总量。API 估值保留已测量的缓存写入，缺少单价时说明原因并显示可估算的小计。
- 更新失败会保留提示，直到较新的成功结果取代。加强诊断遮罩与 Codex 缓存范围，改善迁移重试清理、Windows 开机启动及系统托盘“打开”操作。

## 安装包

- macOS Apple Silicon：`One-More-Prompt-1.0.0.dmg`，Developer ID 签名并经 Apple 公证。
- Windows x64：`One-More-Prompt-1.0.0-windows-x64-portable.zip`，未签名；解压完整文件夹后运行 `one-more-prompt.exe`。

SHA-256: [SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt) / [SHA256SUMS-windows.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS-windows.txt)

安装或运行 App 只需下载 DMG 或 ZIP。[SHA256SUMS.txt](https://github.com/alanchill-dev/one-more-prompt/releases/download/v1.0.0/SHA256SUMS.txt) 列出文件的哈希值，供需要时核对下载文件是否完整；它不是安装程序，也不是数字签名。

## 注意事项

- Windows 需要 Microsoft WebView2。SmartScreen 或企业策略可能警告或阻止未签名程序。设置存放在普通用户数据目录，不随 ZIP 移动。
- 替换 macOS 应用或整个 Windows 文件夹前先退出应用，偏好设置及本地数据会保留。不含自动安装、自动更新源文件或管理员配置流程。
- 版本检查匿名查询项目的 GitHub 正式版本端点，不发送 Codex 凭据、提示词、项目名称或会话历史。
- 目前不含 Linux、Intel Mac、原生 Windows ARM 或自定义 Windows Credential Manager 存储支持。
- 已完成自动化测试、安装包检查，以及当前用户账号下的 macOS 启动检查。本次安装包未重新执行 Windows x64 与 macOS 干净账号完整验收；项目所有者已在知悉这些限制后批准发布。
