# One More Prompt v1.0.0 — Notas de la Versión

> v1.0.0 es la primera versión pública estable para macOS (Apple Silicon) y Windows (x64).

## Novedades

- Un espacio dedicado a Codex: límites de cuenta, reinicios, actividad local de Tokens, Proyectos y Línea de tiempo.
- Hoy como vista inicial, colores de modelos y cambio completo entre Tokens y valoración de API. Las estimaciones, los precios de modelos y sus cálculos usan la moneda seleccionada; son una referencia de uso, no una factura.
- Navegación Proyecto → Sesión → Prompt con texto original, duración, modelos y agentes principales/secundarios. Los elementos fijados se mantienen al cambiar de fecha. Un `>` marca un total con duraciones ausentes o trabajo aún en curso.
- Los registros `.jsonl` y `.jsonl.zst` comprimidos comparten cálculos, fechas, IDs de prompts y navegación. El análisis muestra el número real de archivos comprobados y totales.
- La configuración inicial de tres pantallas empieza por elegir y guardar el idioma, que se conserva en el espacio de trabajo y la guía opcional. Proyectos, sesiones, prompts y descripciones de agentes de demostración están en los nueve idiomas. Repetir la guía y comprobar Codex tienen entradas separadas; la primera configuración sigue siendo obligatoria.
- Identidad e identificadores internos unificados en One More Prompt, con migración única de los datos y ajustes existentes.
- Inglés predeterminado, además de chino tradicional y simplificado, japonés, coreano, español, portugués de Brasil, alemán y francés.
- Comprobación automática de versiones estables, con la comprobación manual siempre disponible en Ajustes. El icono compacto con un punto solo aparece justo a la izquierda de Ajustes al confirmar una versión estable más reciente para la plataforma actual. Las descargas se abren externamente y la sustitución sigue siendo manual.
- Se corrigieron los totales de Tokens de registros repetidos y sesiones continuadas, la deduplicación entre conversaciones y los totales de razonamiento en historiales normales y comprimidos. Las estimaciones API conservan las escrituras de caché medidas y explican los precios ausentes con el subtotal disponible.
- Los errores de actualización permanecen visibles hasta un resultado correcto más reciente. Se mejoraron el enmascaramiento de diagnósticos, el aislamiento de la caché de Codex, la limpieza tras reintentar migraciones, el inicio automático en Windows y la acción Abrir de la bandeja.

## Paquetes

- macOS Apple Silicon: `One-More-Prompt-1.0.0.dmg`, firmado con Developer ID y notarizado por Apple.
- Windows x64: `One-More-Prompt-1.0.0-windows-x64-portable.zip`, sin firma; extrae toda la carpeta y ejecuta `one-more-prompt.exe`.

SHA-256: `SHA256SUMS.txt` / `SHA256SUMS-windows.txt`

## Detalles Importantes

- Windows requiere Microsoft WebView2. SmartScreen o las políticas de empresa pueden advertir o bloquear apps sin firma. Los ajustes están en los datos normales del usuario y no viajan con el ZIP.
- Cierra la app antes de reemplazar la aplicación de macOS o toda la carpeta de Windows. Se conservan preferencias y datos locales. No hay instalación automática, feed de actualización ni configuración de administrador.
- La comprobación consulta anónimamente el endpoint estable de GitHub del proyecto, sin enviar credenciales Codex, prompts, nombres de proyectos ni historial de conversaciones.
- No se incluyen Linux, Mac Intel, Windows ARM nativo ni almacenamiento personalizado de Windows Credential Manager.
- La verificación incluye pruebas automatizadas, comprobaciones de los paquetes y una prueba de inicio de macOS en la cuenta actual. No se repitieron las pruebas completas de aceptación de Windows x64 ni de macOS con una cuenta limpia para estos paquetes; el propietario aprobó la publicación con estas limitaciones conocidas.
