# One More Prompt v1.0.0 — 版本說明

> v1.0.0 是首個正式公開版本，提供 macOS（Apple Silicon）與 Windows（x64）套件。

## 重點

- 以 Codex 為核心的工作區：帳號額度、重置時間、本機 Token 活動、專案與時間軸。
- 預設顯示今天，支援模型配色及完整 Token／API 估值切換；估值、模型單價與計算明細使用所選幣別，API 估值僅供比較用量，並非帳單。
- 依「專案 → 對話 → 提示詞」查看原文、執行時間、模型與主／子代理用量；專案與對話釘選跨日期保留。`>` 提醒總時間含有缺漏紀錄或仍在執行的工作。
- 一般 `.jsonl` 與 `.jsonl.zst` 壓縮紀錄共用計算、日期、提示詞 ID 與瀏覽方式；掃描顯示真實已檢查／總檔案進度。
- 三頁首次設定先選擇並儲存語言，工作區與可選操作導覽沿用這項選擇。示範專案、對話、提示詞與代理說明皆提供九種語言；重新觀看導覽與重新檢查 Codex 各自獨立，首次設定仍必須完成。
- 統一 One More Prompt 的應用程式識別與內部命名，並以一次性遷移保留原有產品資料與設定。
- 英文預設，另提供繁體中文、簡體中文、日文、韓文、西班牙文、巴西葡萄牙文、德文及法文。
- 自動檢查正式新版，設定中的手動檢查入口始終保留。只有確認此平台有較新的正式版時，設定左側才會出現帶提示點的精簡更新圖示。下載透過外部瀏覽器開啟，應用程式仍由使用者手動替換。
- 修正未壓縮與壓縮歷史中的重複紀錄、續接對話、跨對話去重與推理 Token 總量。API 估值保留已量測的快取寫入，缺少單價時說明原因並顯示可估算的小計。
- 更新失敗會保留提示，直到較新的成功結果取代。加強診斷遮罩與 Codex 快取範圍，改善遷移重試清理、Windows 開機啟動及系統匣「開啟」動作。

## 套件

- macOS Apple Silicon：`One-More-Prompt-1.0.0.dmg`，Developer ID 簽章並經 Apple 公證。
- Windows x64：`One-More-Prompt-1.0.0-windows-x64-portable.zip`，未簽章；解壓縮完整資料夾後執行 `one-more-prompt.exe`。

SHA-256: `SHA256SUMS.txt` / `SHA256SUMS-windows.txt`

## 注意事項

- Windows 需要 Microsoft WebView2。SmartScreen 或公司政策可能警告或阻擋未簽章程式。設定使用一般使用者資料目錄，不會隨 ZIP 移動。
- 替換 macOS App 或完整 Windows 資料夾前，先退出程式；偏好設定與本機資料會保留。不含自動安裝、自動更新來源檔或系統管理員設定流程。
- 版本檢查匿名查詢此專案的 GitHub 正式版端點，不傳送 Codex 憑證、提示詞、專案名稱或對話歷史。
- 目前不含 Linux、Intel Mac、原生 Windows ARM 或自訂 Windows Credential Manager 儲存支援。
- 已完成自動化測試、套件檢查，以及目前使用者帳號下的 macOS 啟動檢查。本次套件未重新執行 Windows x64 與 macOS 乾淨帳號完整驗收；專案擁有者已在知悉這些限制後批准發布。
