# Support

## Bug Reports

Search existing issues first. If the problem has not been reported, use the repository's Bug Report issue form with the One More Prompt version, operating-system version and architecture, reproduction steps, and screenshots when useful.

For diagnostic logs, follow [How to Capture Logs for a Bug Report](docs/capture-logs.md). Logs are redacted for common secrets, but review every file before sharing it publicly.

## Feature Requests

Use the repository's Feature Request issue form. One More Prompt is intentionally limited to local Codex usage and prompt activity; other AI providers are outside the project scope.

## Security

Do not report vulnerabilities in a public issue. Follow the [Security Policy](SECURITY.md).

## Service and Account Issues

This repository cannot resolve OpenAI account, billing, quota, or service-availability issues. Check [OpenAI Status](https://status.openai.com/) or the relevant OpenAI support channel.
